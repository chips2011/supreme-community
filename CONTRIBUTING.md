# Contributing

Start with the setup in README.md, then run `npm run typecheck`, `npm test`,
`npm run test:local` and `npm run check:publication` before opening a pull request.

Use a branch and keep changes focused. Explain the user-visible problem, the
change and how you checked it. Add tests when they exercise a meaningful failure
or behavior. Use synthetic fixtures, local stubs and temporary data. Do not
run outreach, spend money or change shared workspaces during automated tests.

File ordinary bugs and feature requests in GitHub Issues. Include reproduction
steps, macOS and Node versions, and redacted logs. Report security issues through
the private process in SECURITY.md.

Contributions are submitted under Apache-2.0. Submit only work you have permission
to contribute and preserve third-party notices. No contributor agreement is
required for this initial community release.

Use respectful, constructive communication. Maintainers may close abusive or
off-topic discussions. Maintenance is best effort; there is no response-time
commitment or hosted support entitlement.
